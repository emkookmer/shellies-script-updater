# Changelog

## 1.0.1

- Replaced both Marketplace icons with a Shelly-blue circle and a white S-shaped update arrow.

## 1.0.0

- Added Home Assistant update entities for Shellies Discovery and Shellies Discovery Gen2+.
- Added detection and storage of existing script versions during setup, including scripts previously installed by HACS.
- Added on-demand installation from published GitHub release archives with SHA-256 verification.
- Preserved existing script permissions during updates and set new scripts to `0644`.
- Declared MQTT and Python Scripts as required Home Assistant integrations.
- Added English setup and entity translations, installation instructions, and HACS and hassfest validation.
